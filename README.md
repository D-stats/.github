# .github レポジトリ

## 概要

このレポジトリは特別なレポジトリで、 `PULL_REQUEST_TEMPLATE.md` などは他のレポジトリのデフォルトとして使用されます。ただし、各レポジトリのものがあれば優先して使用されます。

詳しくはこちら

https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file

## PULL_REQUEST_TEMPLATE.md について

このテンプレートは、プルリクエスト作成時に自動的に表示され、以下のセクションが含まれています：

1. **このPRが必要な理由 / 背景** - 変更の目的やJiraの番号などを記載
2. **変更したこと** - 実装内容の説明（スクリーンショットがあるとベター）
3. **変更しなかったこと** - 意図的に含めなかった変更や将来の対応予定
4. **チェックリスト** - コード実行確認やセルフレビューの完了確認
5. **マージするタイミング** - マージ可能なタイミングの指定
6. **レビュワーへの連絡事項** - レビュー時に必要なリンクや情報
7. **お気持ち** - PRに対する個人的な感想
8. **ノウハウ共有** - 関連するConfluence資料の共有
9. **README更新** - READMEの更新が必要かどうかの確認

各セクションを適切に記入することで、レビュープロセスがスムーズになり、コードの品質向上につながります。
